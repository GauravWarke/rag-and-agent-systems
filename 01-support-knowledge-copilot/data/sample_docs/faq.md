# Resetting your password
To reset your password, open Settings, choose Security, and click "Reset password".
A reset link is emailed to your registered address and expires after 30 minutes.

# Supported file formats
The uploader accepts PDF, PNG, JPEG, and TIFF files up to 25 MB per file.

# Rate limits
The API allows 60 requests per minute per API key. Error code 429 means you are rate limited.
