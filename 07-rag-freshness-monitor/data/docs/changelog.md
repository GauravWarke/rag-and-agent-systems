# Version 2.4 Release Notes
Version 2.4 adds bulk CSV import for contacts and fixes a bug where scheduled reports could be sent twice.

# Version 2.3 Release Notes
Version 2.3 introduces the new API rate limit of 120 requests per minute, up from the previous limit of 60 requests per minute.

# Version 2.2 Release Notes
Version 2.2 adds the Slack integration and improves dashboard load performance for accounts with large widget counts.

# Deprecation Notice
The legacy v1 export endpoint will be removed on 2026-01-01. Migrate to the v2 export endpoint before that date to avoid disruption.
