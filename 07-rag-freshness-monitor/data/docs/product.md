# Pricing Tiers
The Starter plan costs 19 dollars per month, the Growth plan costs 49 dollars per month, and the Enterprise plan is custom priced for large accounts.

# Supported Integrations
The product integrates out of the box with Slack, Salesforce, and Zapier. Additional integrations are added based on customer requests.

# API Rate Limits
The public API allows 120 requests per minute per API key. Requests beyond this limit return an HTTP 429 error with a retry-after header.

# Data Export
Users on the Growth plan and above can export their account data as CSV or JSON at any time from the account settings page.
